# Orca Linux Hardened

Reproducible Linux-only hardening and release harness for `stablyai/orca`.

The repository downloads a pinned upstream source snapshot, applies the reviewed hardening patch, runs Linux lifecycle tests and type checks, then produces an independently named Debian package.

## Release target

- Ubuntu 22.04/24.04 and Debian 12
- x86_64 `.deb`
- package: `orca-hardened`
- executable: `orca-hardened`
- no overwrite of the upstream `orca-ide` package

Build evidence and installable artifacts are generated by GitHub Actions.
